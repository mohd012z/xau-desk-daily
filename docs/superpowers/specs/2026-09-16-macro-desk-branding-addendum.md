# MACRO//DESK Branding Addendum

Date: 2026-09-16
Applies to: `2026-09-16-xau-desk-v4-2-multi-asset-event-intelligence-design.md`

## Product name

The product name is changed from **XAU//DESK** to **MACRO//DESK**.

Primary subtitle:

**FX • Metals • Digital Assets Event Intelligence**

The existing GitHub repository remains `mohd012z/xau-desk-daily` for compatibility. The existing GitHub Pages URL remains unchanged unless the user later explicitly requests a repository/domain migration.

## Main navigation labels

Use these primary labels in the new UI:

- **METALS** — XAU/USD first; room for additional metals later.
- **FX** — currency strength, majors, selected crosses, pip/event reaction.
- **DIGITAL ASSETS** — BTC/USD and ETH/USD first; provider-supported assets can be added later.
- **EVENTS** — scheduled releases, central-bank communication, breaking/unplanned news, live speeches.
- **BRIEF** — compact multi-asset summary, event surprise, measured reaction, historical comparison, source/data quality.

Avoid using `XAU/Crypto` as a product or section name.

## Branding rules

- Keep the `//` visual motif in the brand.
- `MACRO//DESK` is the public display name.
- `MACRO DESK` may be used in accessibility labels and plain-text contexts.
- XAU/USD remains the primary metal instrument but is no longer the product name.
- `DIGITAL ASSETS` is preferred over `CRYPTO` in primary navigation; `crypto` may still be used descriptively inside technical text.
- The dashboard remains analytical: use `UP PRESSURE`, `DOWN PRESSURE`, `MIXED`, `CONFIRMED`, `PARTIAL`, and `DIVERGENCE` for model/market context rather than directive order wording.

## Mobile navigation

Recommended compact bottom bar:

`METALS | FX | EVENTS | DIGITAL | BRIEF`

`DIGITAL` is the short mobile label for `DIGITAL ASSETS`.

## Desktop navigation

Recommended left rail order:

1. BRIEF
2. EVENTS
3. METALS
4. FX
5. DIGITAL ASSETS
6. HISTORY
7. SOURCES / STATUS

This branding addendum supersedes older product-title wording in the v4.1/v4.2 specifications. All implementation plans and user-facing UI changes should use **MACRO//DESK**.
