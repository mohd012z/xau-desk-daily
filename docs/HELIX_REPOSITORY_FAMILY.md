# HELIX Repository Family

Planned naming:
- `helix` — main platform/application source.
- `helix-pulse` — news/event intelligence pipeline.
- `helix-core` — optional future protected backend/strategy engine.
- `helix-relay` — optional future API/feed gateway.
- `helix-vault` — optional future storage/snapshot service.
- `helix-lab` — optional experiments/testing.

Only `helix` and `helix-pulse` are current rename targets; the remaining names describe future separation if it becomes useful.
