# Market Data Semantics

Branding migration must not rename or obscure real market identifiers used by calculations, feeds, or users. Examples intentionally preserved include `XAUUSD`, `XAU/USD`, `USD`, `EUR`, `JPY`, FX, metals, BTC, ETH, timeframes, and indicator terminology where technically meaningful.

VEYRA/HELIX naming replaces product/repository identity, not financial data semantics.
