# HELIX

HELIX is the internal engineering identity behind the public VEYRA application.

Current repository responsibilities include the existing market snapshot, macro/event intelligence, data validation, and web deployment pipeline. The migration is deliberately incremental: preserve trusted behavior, centralize identity/endpoints, add safety audits, migrate public branding, verify CI, then rename the repository.

Public users should see VEYRA branding. Developer documentation may refer to HELIX and HELIX Pulse. The naming separation is organizational/branding separation and is not used as a substitute for access control or secret management.
