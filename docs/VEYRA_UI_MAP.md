# VEYRA Public UI Map

Target public navigation when the full application source is connected:

`HOME | PULSE | CHART | INTEL | MORE`

- **Home**: consolidated status and watchlist.
- **Pulse**: event/news intelligence from HELIX Pulse.
- **Chart**: chart and timeframe interaction.
- **Intel**: strategy/BBMA-derived intelligence without exposing repository/module naming.
- **More**: Alerts, Watchlist, Data Health, Cloud Sync, Account, Settings, Diagnostics, About VEYRA.

The public label does not change legitimate market terminology shown as data, such as XAU/USD or FX.
