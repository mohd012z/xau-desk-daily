# VEYRA Deep Links

Target public scheme when APK/router source is connected:
- `veyra://home`
- `veyra://pulse`
- `veyra://charts`
- `veyra://live`
- `veyra://intelligence`
- `veyra://alerts`
- `veyra://watchlist`
- `veyra://settings`

Deep-link handling must enter the same central router used by normal navigation rather than independently showing/hiding sections.
